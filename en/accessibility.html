Accessibility

Accessibility statement

FHI Engineering is committed to improving accessibility on this site, guided by WCAG 2.1 Level AA principles.

Measures in place

  • “Skip to content” link on every page
  • Semantic HTML (landmarks, headings, form labels)
  • Text contrast aligned with the brand palette
  • Visible focus states on links and controls
  • Alternative text on key images
  • Keyboard navigation for menu and forms

Known limitations

Embedded maps (Google Maps) and some decorative images may not offer an equivalent screen-reader experience. We continue to improve these areas.

Feedback

If you encounter an accessibility barrier, email contacto@fhi.cl with the page and issue. We will respond as soon as possible.
